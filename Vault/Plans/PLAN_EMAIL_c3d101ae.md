Replit Pro


We've just launched our most powerful plan yet - Replit Pro. 
<https://replit.com/pricing>

 Pro brings an expanded set of features for our most avid builders - expanded 
credits, priority support, and exclusive community access - with even more

New Agent Modes



 We've added new Agent modes <https://docs.replit.com/replitai/agent-modes> to 
improve how you build - choose between Economy and Power modes to optimize cost 
& power:

Economy Mode: Optimized for cost. Uses fewer credits per task - prompts cost 
roughly a third of Agent 3, so you can send significantly more prompts for the 
same price.

Power Mode: Optimized for performance. Uses more powerful models for complex 
tasks, larger codebases, and harder problems.


📌 Other new features


 * Background memory compression - Agent no longer stops to "optimize memory," 
so you can now build faster!
 * Expanded MCP integrations - New options available with single-click setup at
replit.com/integrations <https://replit.com/integrations>
 * Skills search - Browse and install popular Skills directly without 
prompting Agent or uploading files.Check it out! 
<https://docs.replit.com/replitai/skills>
 * System theme support - Replit now follows your system preference, or 
manually toggle light/dark from the quick menu
 * Enhanced collaboration - Unlimited Workspaces, simplified sharing, and 
per-Workspace usage tracking on all paid plans
 * Deployment visibility settings - Scope app visibility within your 
organization (Teams and Enterprise)
 * Password manager keyboard navigation - Full keyboard support for logging in 
via password manager extensions

 You can find weekly updates and more in our changelog
